html

Paara começar, gostaria de ressaltar que antes de fazermos coisas incriveis primeiro precisamos entrar em algum programa para que algo reconheça o html, seja pelo visual studio code ou simplesmente por outro arquivo, precisamos de algo para que ele saiba exatamente o que estamos escrevendo, nos aprendemos que podemos screver pelo visual studio code como ja havia ressaltado, pelo sublime ou ate mesmo pelo bloco de notas=, o mais importante é que seja um programa de texto para assim podermos escrever e o programa identificar


o programa identifica atravez do doctype html, para qualquer tag que colocarmos precisamos de simbolos maior e menor pq assim o programa vê o que é texto e o que é tag, faz parte da linguagem em si. o html é uma linguagem para colocarmos em sites, todas os sites tem algum do gênero obrigatoriamente. as tags são basicamente o que queremos colocar nas pastas as mais importantes são: "doctype html" e "html" para o arquivo saber que se trata de um arquivo html e onde ele começa. "head" e "body" para colocar as tags mais relevantes onde no head-cabeça é tudo aquilo que ão esta completamente visivel no site mas é relevante como: titulo, imagem do site, metadados etc. há diversas outras tags como a de paragrafo, de pr botão, aprimorar texto, colocar link de outros sites, colocar imagens, entre outros. Aprendemos as coisas mais importantes do html, o basico para conseguir desenvolver um site com maestria. Claro que existem outro como fazr listas, tabelas ou outros, mas isso é o mais relevante em si.

Github

O github basicamente serve para colocar todos os arquivos em um repositorio, em si, é o mais util e usado pela sua praticidade, podmos colocar diversos arquivos dentro de um repositorio na nuvem para assim não perder nada, podemos até mesmo utilizar o github com repositorio compartilhado para assim ter mais praticidade para trabalhar, fazer trabalhos acadêmicos etc.

git

O git serve praticamente para baixar, salvar ou ate mesmo jogar arquivos dentro do github ou na sua maquina, ele é muito util por que você pode ate mesmo manipular os seus arquivos sem internet. Em si, neste bimestre aprendemos a como dar commit (salvar) e jogar no github em um repositorio atravez do

  1. cd dowloads
  2. git clone (URl)
  3. cd (Nome do repositorio)
  4. git add .
  5. git commit -m "mensagem do save"
  6. git push

basicamente o cd serve para entrar numa pasta no terminal o git clone para clonar/baixar no seu pc o repositorio(os arquivos dele), cd para entrar no seu arquivo, git add . para adicionar tudo ao seu commit, git commit para salar e -m para mandar uma mensagem do que você modificou no seu arquivo e o push serve para você jogar no github
